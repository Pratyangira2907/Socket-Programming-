# Socket Programming Code Library

A static website containing four Python socket-programming examples with tabs and one-click copy buttons.

## Deploy to Vercel

1. Upload this folder's contents to a GitHub repository (keep `index.html` and the `socket` folder at the repository root).
2. Sign in to https://vercel.com/ with GitHub.
3. Choose **Add New → Project**, import the repository, and deploy.
4. No build command or framework preset is required; this is a static site.

The deployed Vercel URL can be opened from any device. The Python programs are displayed for copying; Vercel does not execute TCP/UDP socket servers.
